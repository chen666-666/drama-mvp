# 集号与集数范围

2026-11-04：已正式部署，版本 `episode-ranges-20261104T093335Z`。

视频管理的“核对正片与访问范围”和资料核验的“整理视频”共用以下填写规则：

- 单集填写 `3`；未知留空。
- 同一视频包含多集时填写 `1-12`；也接受 `1–12`、`1至12`，保存后统一为 `1-12`。
- 集号须为正整数，结束不能小于开始；不接受 `12-1`、`0-12`、小数、多个不连续区间。
- 整理视频填写范围时自动选择“多集合集”。一个范围仍对应一个视频、一次下载，不拆分互动或文件。

已保存的范围会在再次核验、目录列表、人工快审、播放选集、下载区及导出中保留。缺集提示识别范围，但范围不替代目录核验和人工抽检，也不会单独证明全剧完整。已生成的历史榜单保持原快照。

## 数据升级与发布
